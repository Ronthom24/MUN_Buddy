# MUN Buddy — Full Final-State Schema Inventory (MySQL files 02-18)

Reference document for the Supabase/Postgres migration. Extracted from the 17 MySQL
schema files (02 through 18), merging every incremental ALTER into each table's
final-state shape. 51 distinct tables. See `database/schema-postgres/` for the
fresh Postgres DDL derived from this inventory (not a 1:1 port — see that
directory's files for the identity-model changes: `organizers` retired in favor
of `profiles`, `organizer_access`/`delegates` keyed by `profile_id`, etc.)
