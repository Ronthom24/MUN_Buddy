# MUN Buddy – Project Status & Master Context

## Project Vision

MUN Buddy is not simply a Model UN management platform.

It is two connected systems:

### Delegate Preparation Platform

Helps delegates:

* Research countries
* Understand committees
* Analyze agendas
* Draft position papers
* Prepare speeches
* Draft resolutions
* Organize notes
* Use AI-assisted research

### Organizer Management Platform

Helps organizers:

* Manage delegates
* Assign countries
* Assign committees
* Monitor preparation
* Review resolutions
* Track participation

---

# Architecture Decisions

## Frontend

Frontend is separate from backend.

Current structure:

```text
frontend/

index.html
login.html

delegate/
dashboard.html

organizer/

assets/
css/
js/
images/
```

Frontend currently uses:

* HTML
* CSS
* Bootstrap
* JavaScript

No React.

No Angular.

No Vue.

Decision:
Keep frontend simple and framework-free.

---

# Core Product Model

This is the most important discovery so far.

Everything revolves around:

```text
Delegate
    ↓
Country
    ↓
Committee
    ↓
Portfolio
    ↓
Agenda
```

All future AI responses must be based on these four elements.

Example:

Country:
India

Committee:
UNSC

Portfolio:
Permanent Representative

Agenda:
Emerging Technologies and International Security

The AI should never answer without this context.
