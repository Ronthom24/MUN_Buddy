# MUN Buddy Backend

This backend directory contains the Node.js and Express scaffold for the MUN Buddy API.

## Installation

1. Open a terminal in the `backend/` folder.
2. Install dependencies:
   ```bash
   npm install
   ```

## Available scripts

- `npm start` - Start the backend in production mode.
- `npm run dev` - Start the backend with `nodemon` for development.

## Environment

Copy `.env.example` to `.env` and update the values for your local environment.

## Project structure

- `src/` - application source files
- `tests/` - automated backend tests
- `.env` - local environment variables (ignored by Git)
- `.env.example` - example environment variables
- `.gitignore` - files and folders ignored by Git
- `package.json` - npm package manifest
- `package-lock.json` - lockfile for installed dependencies
