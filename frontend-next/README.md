# MUN Buddy — frontend

Next.js (App Router) + TypeScript frontend for MUN Buddy. See the [root README](../README.md) for
the full project overview, stack, and setup instructions (environment variables, running both
apps together); this directory is just the Next.js app itself.

## Development

```bash
npm install
npm run dev   # Turbopack dev server, http://localhost:3000
```

## Build

```bash
npm run build
npm start
```
